# uncertainty_formatter
様々なフォーマットの不確かさ付きの値を別のフォーマットに編集しつつ、指数表示や四捨五入の調整を自動で行うソフトウェアです。
一ファイルで動作するのでデスクトップなどに置いておくのがおすすめです。

## usage
不確かさ付きの値は表形式で入力します。
表のうち一列ないし二列を不確かさ付きの値として使用します。
フォーマットによりますが、最初からある中ではlatexのみ`2.35+-0.01e2`の形式を一列で表現し、他のフォーマットではある列に最適推定値、次の列に不確かさを配置します。

画面上のテキストボックスに不確かさ付きの値を含む表を入力し、最適推定値の列を最適推定値を含む列に設定して対応する入力フォーマットをクリックしてください。
出力フォーマット欄に表示されたボタンをクリックすると対応するフォーマットに編集された表がコピーされます。
その際に不確かさ付きの値の書式と指数表示が調整されます。
フォーマットによっては、不確かさの値に応じて不必要な桁を四捨五入します。

## How to add new template
`table_formatter.html`ファイルをメモ帳などで開き、40行目ほどにある`template`配列を編集します。
初めからいくつかのテンプレートが用意されているので、それを参考に追加してください。
```
    name: 名称
    color: ボタンの色
    column: 行を分ける文字列
    row: 列を分ける文字列
    pmParting: 最適推定値と不確かさを分ける文字列。空ならば二列に分けて記述されていると判断
    eParting: 10のn乗を併記する際のnの左に置く文字列を指定。大文字小文字を区別する
    cutoff: 不確かさに合わせて不必要な桁を四捨五入するか指定。true or false
    header: 出力の先頭につける文字列
    footer: 出力の末尾につける文字列
```
